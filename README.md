03. Experience

㈜예측진단기술 · 선임연구원 / 제조 AI·데이터 플랫폼 개발 <sub>(SW 개발팀)</sub>  2025.03 ~ 현재

진동·AE·온도·가스·PLC 데이터를 수집해 운영 화면, 알람, AI 진단으로 전달하는 예지보전 플랫폼을 개발·운영하고 있습니다. 플랫폼에서는 하루 약 310만 건의 센서 데이터를 처리합니다.

최근값은 Redis, 시계열 원본은 InfluxDB, 설비·센서 정보는 MySQL에 저장하도록 구조를 나눴습니다. 그 결과 1년치 집계 조회 시간이 13.4초 → 66ms로 줄었고, 캐시 적중률은 98.29%를 기록했습니다.

현장마다 달랐던 실행 환경과 배포 절차를 Docker Compose와 Nginx 중심으로 표준화했습니다. 신규 현장 구축 시간은 평균 2일 → 30분으로 줄었으며, 서버 이전과 백업·복원 절차도 함께 정리했습니다.

43개 도메인 모듈에서 각각 생성하던 소켓 게이트웨이를 하나로 통합해 중복 리스너 문제를 해결했습니다. AI 추론은 비동기로 분리해 추론 중에도 조회와 화면 응답이 멈추지 않도록 개선했습니다.

울산대학교 대학원 산업 인공지능 연구실 · 석사 연구원 <sub>(지도교수 김종면)</sub>  2023.03 ~ 2025.02

진동·AE·온도 센서 신호를 분석해 정상, 베어링, 기어, 공구 상태를 분류하는 연구를 수행했습니다.

FFT·STFT와 회전성분 기반 신호 압축을 설계하고, 1D-CNN·TabNet·XAI를 이용해 분류 성능과 판단 근거를 검증했습니다.

05. How I Work

기능을 구현하기 전에 현장의 데이터 환경과 운영 방식을 먼저 확인합니다. 같은 문제라도 데이터의 양과 품질, 서버 환경에 따라 필요한 방법이 달라지기 때문입니다.

배포와 장애 대응도 개발의 일부로 생각합니다. 새 현장에서도 같은 방식으로 설치하고 복구할 수 있도록 설정과 절차를 정리해 둡니다.

협력사와 현장 담당자가 같은 기준으로 데이터를 이해할 수 있도록 API 규격과 용어, 위치·시간 정보를 맞추는 데 시간을 들입니다.
